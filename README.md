# Formula 1 Race Intelligence

## Overview

Formula 1 Race Intelligence is a data visualization project designed to explore Formula 1 racing data and identify patterns in driver performance, team standings, tyre strategies, circuit participation, and race reliability.

The project presents racing statistics through interactive visualizations to help users understand performance trends across seasons, teams, drivers, and circuits.

## Live Website

[Formula 1 Race Intelligence](https://f1-race-intelligence-yjbx.onrender.com/)

## Project Objectives

- Analyze driver performance and podium achievements.
- Examine team championship trends across seasons.
- Explore tyre compound strategies and their usage.
- Study circuit-level participation and race distribution.
- Analyze retirements, race failures, and reliability patterns.
- Present Formula 1 statistics through interactive visualizations.

## Key Features

- Interactive Formula 1 data visualizations.
- Driver and team performance analysis.
- Season-wise championship comparisons.
- Tyre strategy exploration.
- Circuit participation analysis.
- Race reliability and DNF analysis.
- Web-based access to the project dashboard.

## Technologies Used

- **Tableau:** Data visualization and dashboard development.
- **Python:** Web integration and application logic.
- **Flask:** Python web framework.
- **HTML and CSS:** Webpage structure and styling.
- **Render:** Web application deployment.
- **GitHub:** Source code management and project documentation.

## Project Workflow

1. Collect and prepare Formula 1 racing data.
2. Clean and organize the data for analysis.
3. Create visualizations and dashboards in Tableau.
4. Integrate the dashboard into a web interface using Flask.
5. Deploy the web application on Render.
6. Publish the project link for online access.

## Target Audience

This project can be useful for Formula 1 fans, students, data visualization learners, and anyone interested in exploring motorsport statistics and performance trends.
